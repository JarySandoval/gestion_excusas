# Control de Acceso Basado en Roles (RBAC)

La **IED La Victoria** maneja una estructura de seguridad jerárquica estricta. El sistema reconoce tres roles institucionales en la tabla `rol`:

1. **Coordinador** (`id_rol = 1`): Máxima autoridad institucional y de convivencia.
2. **Docente** (`id_rol = 2`): Equipo pedagógico responsable de la verificación y seguimiento en aula.
3. **Estudiante / Acudiente** (`id_rol = 3`): Usuarios titulares que radican y justifican inasistencias.

## 🛡️ Implementación de Middlewares en el Backend

El backend en Express implementa middlewares reutilizables para garantizar el cumplimiento de la matriz RBAC:

### 1. `verifyToken`
Verifica la validez y vigencia de la firma JWT en la cabecera `Authorization: Bearer <token>`. Inyecta el payload del usuario en `req.user`.

```javascript
// backend/middlewares/auth.middleware.js
export function verifyToken(req, res, next) {
  const authHeader = req.headers.authorization;
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ success: false, message: 'Token de acceso no proporcionado.' });
  }
  const token = authHeader.split(' ')[1];
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (err) {
    return res.status(401).json({ success: false, message: 'Token inválido o expirado.' });
  }
}
```

### 2. `requireStaff`
Restringe el endpoint exclusivamente a personal institucional (Coordinadores con rol `1` o Docentes con rol `2`).

```javascript
// backend/middlewares/rbac.middleware.js
export function requireStaff(req, res, next) {
  if (req.user && (Number(req.user.id_rol) === 1 || Number(req.user.id_rol) === 2)) {
    return next();
  }
  return res.status(403).json({
    success: false,
    message: 'Acceso denegado: Esta acción requiere privilegios de personal docente o coordinador.'
  });
}
```

### 3. `requireCoordinador`
Garantiza el cumplimiento estricto de la **HU-07**, reservando la generación y descarga masiva de reportes en formato CSV únicamente al Coordinador institucional (`id_rol = 1`).

```javascript
// backend/middlewares/rbac.middleware.js
export function requireCoordinador(req, res, next) {
  if (req.user && Number(req.user.id_rol) === 1) {
    return next();
  }
  return res.status(403).json({
    success: false,
    message: 'Acceso restringido: Solo la Coordinación de la institución puede exportar reportes consolidados (HU-07).'
  });
}
```
